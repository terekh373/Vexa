# @vexa/web

Веб-клієнт Vexa: React 19 + Vite, JavaScript / JSX (ТЗ, розділ 6).

Установка, запуск, порти, демо-акаунти й скрипти — у [кореневому README](../../README.md).
Контракт з API — [`docs/frontend-api-map.md`](../../docs/frontend-api-map.md).

Запуск із кореня репозиторію: `npm run dev:web` (Vite на http://localhost:5173).
